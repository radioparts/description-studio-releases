# Description Studio

Downloads for Description Studio, the Radio Parts editor for product descriptions in Business Central.

**Get it:** open [Releases](../../releases/latest) and download `description-studio.exe`. It's a single
portable program: put it anywhere and run it. It needs no install (Windows 10/11).

**Updates:** the app checks this page when it starts and offers **Update and restart** when there's a
new version. You can also use **... > Check for updates**.

The first time it opens, it walks you through signing in with your Radio Parts Microsoft account.
Loading and saving items uses your own Business Central permissions.

This repository only holds the released program. The source code is kept privately.
